1
바이브런 교육과정 (2주)
6/11(목) OT 밤 10시 ~ 6/23(월)
6/11~6/14 웹명함 제작 (과제 제출)
6/15~6/22 웹게임 제작·배포 → 모바일게임 제작·배포
6/23 과제 제출 오후 4시 (6/24 피드백 + 팀빌딩) + 추가 교육 자료 오픈
2
게임런 팀 개발과정 (2주)
6/25(수) OT 밤 10시 ~ 7/7(월)
팀빌딩 후 실제 게임 공동 개발 · 배포
3
발표회 & 리뷰 기간 (1주)
7/9(수) 발표회 · 7/9~7/15 리뷰 기간
발표 핵심: 제작의도 · 제작목표 · 트러블슈팅
리뷰 기간 중 실 사용자 피드백 수집 → 포트폴리오 반영 가능
7/16(목) 공식 과정 종료 · 수료증 + 수강확인증 발급

💼 나도 대상일까? — 직군별 바이브런이 필요한 이유

바이브런은 직군 역량을 가르치는 곳이 아닙니다.
각자 자기 무기 — 사업PM은 BM, 기획자는 시스템, UI/UX는 화면, 프로그래머는 코드 —
를 들고 들어와, 그 무기에 "AI로 끝까지 만들어본 경험"이 더해진 채로 나가는 5주입니다.

2026년 면접관이 가장 보고 싶어 하는 한 가지

"이 사람, 자기 직군 일을 AI 워크플로로 끝까지 돌려봤나?"

📊
사업 PM
기획서 쓰고 외주 맡기는 PM이 아닌, MVP를 직접 빌드해 BM 가설을 검증한 PM이 면접에서 살아남습니다. "이 BM, 게임으로 만들어 50명에게 돌려봤습니다" 한 줄이 면접의 카테고리를 바꿉니다.
🗂️
개발 PM
AI 코딩으로 개발 사이클이 분 단위로 빨라진 시대, 직접 워크플로를 돌려본 PM만 합리적인 일정 산정이 가능합니다. 기획 → 프로토 → 배포 → 디버깅 전체 사이클을 손으로 한 번 돌리는 5주.
🗺️
게임 기획
기획서만 쓰는 기획자의 시대는 저물고, 프로토타입을 직접 만들어 검증한 기획자가 채용됩니다. 면접관 앞에서 노트북을 열고 본인 메커닉을 즉석 시연하는 5분이 면접 분위기를 통째로 바꿉니다.
🎛️
운영 (게임 운영/CS)
운영 업무 상당 부분이 AI 자동화로 대체되는 중. 문의 자동분류 봇, KPI 대시보드, 어드민 페이지를 직접 빌드하는 운영자로 포지셔닝 자체가 바뀝니다.
🔍
QA
수동 테스트만 하는 QA는 평가절하되고, 테스트 자동화 스크립트를 직접 짤 수 있는 QA의 시장가치가 올라갑니다. 내가 만든 게임에 직접 테스트 자동화를 적용해보는 이 조합, 신입 시장에서 거의 만나기 어렵습니다.
🎨
UI/UX
Figma 시안만 잘 그리던 시대는 지났습니다. 내가 설계한 화면이 실제로 작동하는 모습까지 보여줄 수 있는 디자이너를 찾습니다. 면접에서 정적 목업이 아닌, 실제 동작하는 UI를 시연합니다.
💻
프로그래밍
GitHub 커밋 상당 비율이 AI가 작성한 시대, 신입 채용공고에 Cursor·Copilot·Claude Code 사용 경험이 명시되는 흐름입니다. 단순 코딩이 아닌 "AI 페어 프로그래밍으로 풀스택 빌드"하는 워크플로 경험. 다른 직군과 협업하며 나만의 AI 활용 패턴을 정립합니다.

🏆 5주 후 내 손에 남는 것 — 총 6가지

1
나만의 웹명함 AI로 만든 개인 브랜딩 페이지
2
웹게임 배포본 내가 기획·개발·배포한 실제 웹게임
3
모바일게임 배포본 링크만 있다면 스마트폰에서 바로 실행 가능
4
팀 협업 게임 팀 협업을 통한 직무스킬 포함 게임 완성작
5
실 사용자 리뷰 리뷰 기간(7/9~7/15) 중 실제 유저 후기·피드백 수집 → 포트폴리오에 바로 적용 가능
6
수료증 + 수강확인증 전 과정 수료 시 공식 발급 취업 서류에 바로 활용
